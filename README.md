# Do'kon yordamchi

Instagram va Telegram orqali sotadigan kichik do'konlar uchun katalog va buyurtma tizimi.

- `/` — xizmat haqida sahifa (do'kon egalari uchun)
- `/demo/` — jonli demo katalog (Telegram Mini App sifatida ham ishlaydi)

Qanday ishlaydi: mijoz katalogni ochadi → mahsulot, razmer, rangni tanlaydi → ism, telefon, manzilni yozadi → buyurtma darhol do'kon egasining Telegramiga keladi ("Qabul / Yuborildi / Bekor" tugmalari bilan).

Texnologiyalar: HTML/CSS/JS, Supabase (baza + Edge Functions), Telegram Bot API, Vercel.
